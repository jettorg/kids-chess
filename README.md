# 우리 체스 (Kids Chess)

아이와 함께 두는 체스 게임. 웹 브라우저에서 돌아가고, 설치할 것도 계정도 없습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

빌드와 검증:

```bash
npm run build      # dist/ 에 정적 파일 생성 (tsc 검사 포함)
npm test           # 규칙 엔진·AI·콘텐츠 테스트 54개
npm run typecheck
```

`dist/` 는 정적 파일이라 GitHub Pages, Vercel, Netlify 어디든 그냥 올리면 됩니다.
`vite.config.ts` 의 `base: './'` 덕분에 하위 경로에 올려도 동작합니다.

## 화면 네 개

| 화면 | 하는 일 |
| --- | --- |
| 대국 | 둘이서 번갈아 두기, 또는 컴퓨터와 대국 |
| 배우기 | 말 한 종류씩 익히는 연습 (상대는 움직이지 않음) |
| 퍼즐 | 한 수로 체크메이트 만드는 문제 6개 |
| 말 도감 | 말별 이동 규칙과 점수, 특수 규칙 설명 |

## 아이를 위해 넣은 것

- **판이 화면에 맞춰 커집니다**: 고정 상한 없이 남는 공간을 계산해서 판을 키웁니다. 세로로 든 아이패드에서는 폭을 거의 다 씁니다. 대국 중에는 잡은 말 자리를 미리 확보해 두어 첫 잡기에 판 크기가 변하지 않습니다.
- **갈 수 있는 칸 하이라이트**: 말을 누르면 갈 수 있는 칸에 점, 잡을 수 있는 말에는 빨간 테두리가 생깁니다. 규칙을 몰라도 둘 수 있습니다.
- **잘못된 수**: 칸이 살짝 흔들리고 낮은 소리가 납니다. 야단치는 느낌이 없도록 했습니다.
- **체크 표시**: 위험한 킹이 있는 칸이 빨갛게 깜박입니다.
- **난이도 3단계**: 🐣 병아리(아무 데나) → 🐶 강아지(잡을 수 있으면 잡기) → 🦊 여우(3수 탐색). 병아리는 아이가 이길 수 있습니다.
- **힌트**: 3수 탐색으로 좋은 수를 찾아 파랗게 표시합니다.
- **되돌리기**: 컴퓨터와 둘 때는 내 차례가 올 때까지 한 번에 되돌립니다.
- **승격 선택**: 폰이 끝까지 가면 그림 버튼으로 고릅니다.
- **소리**: 오디오 파일 없이 WebAudio 로 만든 짧은 효과음. 끌 수 있습니다.
- **큰 터치 영역**: 모든 버튼이 최소 44px. 태블릿에서 손가락으로 누르기 좋습니다.
- **대국 중 설정 접기**: 첫 수를 두면 상대·색 설정이 한 줄 요약으로 접혀 판에 집중됩니다. 바꾸기 버튼으로 다시 펼칩니다.
- **탭과 드래그 모두 지원**: 두 번 탭해도, 끌어다 놓아도 움직입니다.

## 구조

```
src/
  engine/     체스 규칙 (UI 와 완전히 분리, DOM 의존 없음)
    types.ts      말·칸·수 타입
    position.ts   좌표 변환, FEN 읽기/쓰기
    moves.ts      수 생성, 공격 판정, 수 적용
    status.ts     체크메이트·스테일메이트·무승부 판정
    san.ts        기보 표기 (Nf3, exd5, O-O, Qh5#)
    game.ts       한 판의 진행·기보·되돌리기
  ai/ai.ts    난이도별 수 선택 (알파베타 탐색)
  ui/         화면
    board.ts      체스판 렌더링과 조작
                  판 크기는 style.css 의 --board 예산 계산으로 결정된다
    app.ts        화면 전환, 모드, 저장
    pieces.ts     말 그림 (직접 그린 SVG, 외부 이미지 없음)
    sound.ts      WebAudio 효과음
    confetti.ts   승리 축하 효과
    ko.ts         한글 조사 처리 ("폰으로" / "나이트로")
  data/       배우기 레슨과 퍼즐
tests/        엔진·AI·콘텐츠 테스트
```

의존성은 Vite, TypeScript, Vitest 뿐입니다. 체스 라이브러리도, 말 이미지도, 효과음 파일도 쓰지 않습니다.

## 규칙 구현 범위

일반 이동과 잡기, 캐슬링(양쪽), 앙파상, 폰 승격 4종, 체크·체크메이트·스테일메이트,
무승부 3종(50수 규칙, 3회 동형 반복, 기물 부족)까지 정식 규칙 전체를 구현했습니다.

정확성은 perft 로 검증했습니다. 초기 배치 깊이 4까지(197,281), Kiwipete 깊이 3까지(97,862),
앙파상·승격 특수 배치까지 공식 수치와 일치합니다.

## 저장

브라우저 localStorage 에 설정, 진행 중인 판, 레슨·퍼즐 완료 기록을 저장합니다.
서버로 아무것도 보내지 않습니다.
