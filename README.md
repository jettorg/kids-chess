# 우리 체스 (Kids Chess)

[English](README.en.md)

아이와 함께 두는 체스 게임. 웹 브라우저에서 돌아가고, 설치할 것도 계정도 없습니다.
한 번 열어두면 인터넷이 없어도 열립니다.

**바로 열기: https://jettorg.github.io/kids-chess/**

태블릿에서는 사파리·크롬의 **홈 화면에 추가**로 앱처럼 쓸 수 있습니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run dev:host     # 같은 와이파이의 태블릿에서도 접속
```

검증:

```bash
npm test             # 규칙 엔진·탐색·콘텐츠 단위 테스트 (Vitest)
npm run test:e2e     # 빌드 후 실제 브라우저 테스트 (Playwright, 크로미움 + WebKit)
VISUAL=1 npx playwright test e2e/visual.spec.ts   # 시각 회귀 (로컬 macOS 기준 이미지)
npm run test:all     # 둘 다
npm run typecheck
npm run build        # dist/ 에 정적 파일 생성 (서비스 워커 포함)
```

## 배포

main 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 단위 테스트 → 빌드 → 브라우저 E2E 순으로
검사한 뒤 GitHub Pages 에 배포합니다. 어느 하나라도 깨지면 배포되지 않습니다.

`dist/` 는 정적 파일이라 다른 곳에 올려도 됩니다. `vite.config.ts` 의 `base: './'` 덕분에 하위 경로에서도 동작합니다.

## 화면 네 개

| 화면 | 하는 일 |
| --- | --- |
| 대국 | 둘이서 번갈아 두기, 또는 컴퓨터와 대국 (난이도 5단계) |
| 배우기 | 말 6종 익히기 + 체크 벗어나기·캐슬링·승격·앙파상·체크메이트·길 찾기 (12개) |
| 퍼즐 | 한 수·두 수 메이트, 포크, 핀, 공짜 말 잡기 266개. 흑 차례 문제는 판을 뒤집어 보여주고 상대 응수는 자동 |
| 말 도감 | 말별 이동 규칙과 점수, 특수 규칙 설명 |

## 언어

한국어와 영어를 지원합니다. 처음 열면 브라우저 언어에 맞춰 정해지고, 상단의 **한국어 | English** 버튼으로
언제든 바꿀 수 있습니다. 선택은 기기에 저장됩니다.

문구는 `src/i18n/ko.ts` 와 `src/i18n/en.ts` 에 있습니다. 두 파일은 같은 키를 가져야 컴파일되므로
한쪽만 고치면 타입 검사에서 바로 잡힙니다. 레슨·퍼즐·도감처럼 내용이 긴 것은 `src/data/` 에서
`{ ko, en }` 묶음으로 관리합니다.

## 아이를 위해 넣은 것

- **판이 화면에 맞춰 커집니다**: 고정 상한 없이 남는 공간을 계산해서 판을 키웁니다. 세로로 든 아이패드에서는 폭을 거의 다 씁니다. 대국 중에는 잡은 말 자리를 미리 확보해 두어 첫 잡기에 판 크기가 변하지 않습니다.
- **갈 수 있는 칸 하이라이트**: 말을 누르면 갈 수 있는 칸에 점, 잡을 수 있는 말에는 빨간 테두리가 생깁니다. 규칙을 몰라도 둘 수 있습니다.
- **잘못된 수**: 칸이 살짝 흔들리고 낮은 소리가 납니다. 야단치는 느낌이 없도록 했습니다.
- **체크 표시**: 위험한 킹이 있는 칸이 빨갛게 깜박입니다.
- **난이도 5단계**: 🐣 병아리(아무 데나) → 🐶 강아지(잡을 수 있으면 잡기) → 🦊 여우 → 🐻 곰 → 🦉 부엉이. 노드 예산으로 정해서 어느 기기에서나 세기가 같습니다. 부엉이는 60만 노드(이 맥에서 약 3초)를 봅니다.
- **화면이 멈추지 않습니다**: 탐색은 Web Worker 에서 돌아서 컴퓨터가 생각하는 동안에도 화면이 매끄럽습니다.
- **힌트**: 탐색으로 좋은 수를 찾아 파랗게 표시합니다.
- **되돌리기**: 컴퓨터와 둘 때는 내 차례가 올 때까지 한 번에 되돌립니다.
- **승격 선택**: 폰이 끝까지 가면 그림 버튼으로 고릅니다.
- **소리**: 오디오 파일 없이 WebAudio 로 만든 짧은 효과음. 끌 수 있습니다.
- **키보드로도 둘 수 있습니다**: Tab 으로 판에 들어가 방향키로 옮기고 Enter 로 고릅니다. 칸마다 "e4, 흰색 폰, 이동 가능" 같은 라벨이 있어 스크린리더로도 됩니다. 결과 창과 승격 창은 초점을 가두고 Esc 로 닫힙니다.
- **기록 옮기기**: ❔ 버튼에서 코드를 복사해 다른 기기에 붙여 넣으면 푼 문제와 레슨 기록이 합쳐집니다. 서버 없이 됩니다.
- **새 버전 안내**: 배포되면 "새 버전이 있어요" 안내가 떠서 새로고침 한 번으로 바뀝니다.
- **큰 터치 영역과 충분한 명도 대비**: 모든 버튼이 최소 44px, 글씨 대비는 WCAG AA 기준입니다.
- **대국 중 설정 접기**: 첫 수를 두면 상대·색 설정이 한 줄 요약으로 접혀 판에 집중됩니다.
- **탭과 드래그 모두 지원**: 두 번 탭해도, 끌어다 놓아도 움직입니다.

## 퍼즐 늘리기

퍼즐은 직접 만든 입문 6개와 Lichess 퍼즐 데이터베이스(CC0)에서 가져온 260개입니다.
가져온 문제는 우리 엔진으로 정답 수열의 합법성과 메이트를 검증했고, 테마별로 난이도 순으로 이어집니다.

```bash
curl -s https://database.lichess.org/lichess_db_puzzle.csv.zst | zstd -dc | head -n 400000 > puzzles.csv
npx tsx scripts/import-puzzles.ts puzzles.csv --mate1=100 --mate2=60 --fork=40 --pin=20 --hanging=40 --max-rating=1600
```

## 구조

```
src/
  engine/     체스 규칙 (UI 와 완전히 분리, DOM 의존 없음)
    types.ts      말·칸·수 타입
    position.ts   좌표 변환, FEN 읽기/쓰기
    moves.ts      수 생성, 공격 판정, 수 적용
    status.ts     체크메이트·스테일메이트·무승부 판정
    san.ts        기보 표기 (Nf3, exd5, O-O, Qh5#)
    game.ts       한 판의 진행·기보·되돌리기
    zobrist.ts    Zobrist 해시 (make/unmake 가 증분 갱신)
  ai/
    ai.ts         알파베타 + 정지 탐색 + 반복 심화 + 전치 테이블(Zobrist) + 킬러/히스토리 + PeSTO 평가 + 오프닝 북
    worker.ts     탐색을 돌리는 Web Worker
    client.ts     앱이 쓰는 창구 (Worker 없으면 메인 스레드로 대체)
  i18n/       문구 사전 (ko.ts, en.ts) 와 언어 선택
  ui/
    app.ts        화면 전환, 한 판의 진행, 컴퓨터 상대, 판정
    panels.ts     오른쪽 패널 (대국·배우기·퍼즐) 과 말 도감
    dialogs.ts    결과 창, 승격 선택 창
    help.ts       기록 옮기기·진단 정보·문제 신고 대화상자
    focus.ts      대화상자 초점 가두기, 움직임 줄이기 감지
    transfer.ts   기록 전송 코드 인코딩·병합
    errors.ts     최근 오류 기록 (기기에만)
    board.ts      체스판 렌더링, 포인터·키보드 조작, 접근성 라벨
    storage.ts    설정·진행·저장 (localStorage)
    pieces.ts     말 그림 (직접 그린 SVG, 외부 이미지 없음)
    sound.ts      WebAudio 효과음
    confetti.ts   승리 축하 효과
    ko.ts         한글 조사 처리 ("폰으로" / "나이트로")
  data/       배우기 레슨(목표 7종), 퍼즐(입문 + 가져온 것, 테마 5종), 도감
scripts/
  make-icons.mjs        앱 아이콘·공유 이미지 생성
  import-puzzles.ts     Lichess 퍼즐 가져오기
e2e/          Playwright 브라우저 테스트 (크로미움·WebKit, 시각 회귀)
tests/        Vitest 단위 테스트
```

의존성은 Vite, TypeScript, Vitest, Playwright(테스트), tsx(스크립트) 뿐입니다.
체스 라이브러리도, 말 이미지도, 효과음 파일도 쓰지 않습니다.

## 규칙 구현 범위

일반 이동과 잡기, 캐슬링(양쪽), 앙파상, 폰 승격 4종, 체크·체크메이트·스테일메이트,
무승부 3종(50수 규칙, 3회 동형 반복, 기물 부족)까지 정식 규칙 전체를 구현했습니다.

정확성은 perft 로 검증했습니다. 초기 배치 깊이 4까지(197,281), Kiwipete 깊이 3까지(97,862),
앙파상·승격 특수 배치까지 공식 수치와 일치합니다.

## 오프라인과 저장

빌드 때 만들어지는 서비스 워커(`sw.js`)가 페이지와 자산을 미리 담아 두어, 한 번 연 뒤에는
인터넷 없이도 열립니다. 새 버전을 배포하면 다음에 열 때 자동으로 바뀝니다.

설정, 언어, 진행 중인 판, 레슨·퍼즐 완료 기록은 브라우저 localStorage 에 저장됩니다.
서버로 아무것도 보내지 않습니다.
